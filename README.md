# E-Commerce Sales & Profitability Analysis (SQL & Power BI)

## Business Overview
This project presents an end-to-end analytics solution designed to evaluate sales performance, profitability margins, customer purchasing trends, and product return patterns for an E-commerce business. 

------------------------------

## Tools Used
**Database Management:** SQL Server (SSMS) - DDL, DML, Advanced Aggregations, Joins.
**Business Intelligence & Visualization:** Power BI Desktop - DAX Measures, Visual Data Modeling.
**Data Processing:** Microsoft Excel / CSV.

------------------------------

## Key Metrics & Insights
* **Total Revenue:** ~$2.88M generated across multiple key regional markets.
* **Profitability:** Achieved an optimal **17.92% Profit Margin**, reflecting healthy unit economics.
* **Product Performance:** Technology products drive the highest revenue share, with Laptops leading total profitability.
* **Return Analysis:** Identified top returned products and return drivers to help optimize operational/logistical efficiency.
